# RMBench 任务取证

## 三条时间线

| 字段 | 证据 | 用途 |
| --- | --- | --- |
| `observable_onset` | 最早经复核的可见变化。例如盖子仍被握持，但目标色块已经露出 | 更新该帧起的可见事实 |
| `outcome_frame` | 支持阶段结果的画面。例如盖子与夹爪分离，目标仍处于要求状态 | 追加已观察的阶段结果 |
| `handoff_frame` | 下一操作所需的物理条件成立。例如下一操作的工作区已清空 | 审查阶段交接与监督边界 |

复核时另记官方子任务起始帧与实际首个监督采样点。这些时间可能不同。物理变化处于两个采样时刻之间时，可写“最迟在第 X 帧可观察”，并记录证据范围。对终段与无后继操作的阶段，交接时间可为空。

## 三类已建立的判据

### `cover_blocks`

- 用初始观测建立颜色与位置绑定，每条轨迹单独核对。ROI 颜色计数可定位色块出现或消失，机械臂挡住色块时仅支持“被遮挡”。
- 判定已盖住时查看目标盖子是否对齐并落在目标位置。视觉位置证据配合松夹和静止帧，支持阶段完成。盖子在空中经过目标只支持当时遮挡。
- 揭盖时先记录对应色块已出现；盖子的放妥及夹爪撤离另记。保留已经完成的盖／揭经历和初始绑定，更新有新证据的动态状态。

### `put_back_block`

- 首帧锁定原垫，分别复核起始、中央、回原垫。区分悬持于目标上方、已到位仍夹持、松夹后在支撑面保持。
- 按键按可见证据记录下压、退臂和反馈。画面仅支持机械动作时，Memory 可写 “The gripper pressed down at the button and then moved away.”。
- 遮挡后回看腕部，并以终帧确认动作完成后的可见位置。原垫身份与方块当前位置分别保留。

### `battery_try`

- 区分左右电池、相对上一次的调转、入槽与松夹。只有电极实物标记可读时才写绝对极性。
- 仪表观测要求表盘与枢轴可辨，指针可从枢轴辨认。留意镜头内臂上红标或高饱和反光。表盘被遮挡时记录最后可辨方向和当前遮挡。
- 从可读画面记录指针变化，从入槽和松夹证据判定试插结果。把“某次尝试后看到指针转动”写作观察顺序，与物理因果分别处理。

## 其他官方任务的查证起点

以下检查项用于定位证据，具体判据随轨迹和视角复核。

| 任务 | 优先核对 |
| --- | --- |
| `observe_and_pickup` | 遮挡墙出现前的目标身份与位置，墙出现后的可见范围，以及抓取后目标与桌面的分离 |
| `press_button`、`blocks_ranking_try` | 按键身份、实际下压和释放、显示反馈与已尝试的顺序。每次重复按压按实际证据计数 |
| `classify_blocks`、`storage_blocks` | 每个物体的身份与分类依据，物体实际进入容器，松夹后留在容器里；一并夹持两块时分别核对 |
| `place_block_mat`、`rearrange_blocks` | 物体原位、目标垫、暂放位置与夹爪释放。一个官方子任务包含搬出又搬回时分别记录两次结果 |
| `swap_blocks`、`swap_T` | 两个物体的身份及各自原位，临时放置、交叉移动与最终互换。手移动到约定位置与物体落稳分别记录 |

## 怎样判断修订是否生效

在官方切换前后各选实际监督点，展开目标 Memory 与其上一决策收到的参考 Memory。检查在刚出现的可见事实、最终物理交接及终帧上，摘要是否持续一致。验证恰逢遮挡或动作仍在进行的反例。片段复核可按片段交付，完成整条时按实际范围报告。

原始任务和命名见 [RMBench 官方仓库](https://github.com/RoboTwin-Platform/RMBench)。高层语言摘要思想见 [MEM](https://arxiv.org/abs/2603.03596v2)。

# RMBench 任务取证

## 三条时间线

| 字段 | 证据 | 用途 |
| --- | --- | --- |
| `observable_onset` | 最早经复核的可见变化。例如盖子仍被握持，但目标色块已经露出 | 更新该帧起的可见事实 |
| `outcome_frame` | 支持阶段结果的画面。例如盖子与夹爪分离，目标仍处于要求状态 | 将过程概括为有证据的阶段结果 |
| `handoff_frame` | 下一操作所需的物理条件成立。例如下一操作的工作区已清空 | 审查阶段交接与监督边界 |

复核时另记官方子任务起始帧与实际首个监督采样点。官方起始帧可以早于动作发起。例如揭盖区间已经开始，夹爪尚未移动时，Memory 继续记录盖子在原位。物理变化处于两个采样时刻之间时，可写“最迟在第 X 帧可观察”，并记录证据范围。对终段与无后继操作的阶段，交接时间可为空。

## 通用取证判据

- **持续状态。** 同时核对同一对象在不同视角下的身份、可见性和支撑关系。只看到目标位置附近的物体，继续核对夹持、接触和松夹后是否留在原位。遮挡期间可保留最后一次可辨状态，措辞要体现观察时间。
- **动态结束。** 找到动作仍成立的末段，再看一次脱离、放稳、退开或静止的窗口，确定过程描述的排他结束帧。已有结果后，后续摘要只保留所需结果与当时状态。短暂消失、出画和手部遮挡需要用其他可辨视角排查。
- **完成与效果。** 按压、插入、释放按画面建立机械结果。任务规定的额外反馈依据可读的指示器、表盘或其他已采集的证据分别确认。重试逐次保留实际结果，掉落、回退、重抓和复位时更新对应的当前状态。
- **双向变化。** 同时查离开旧状态和进入新状态。目标可以逐渐被遮住，也可以逐渐露出。物体可以松夹放稳，也可以再次被拿起。记录能辨认的中间状态及它何时结束。

## 三类已建立的判据

### `cover_blocks`

- 用初始观测建立颜色与位置绑定，每条轨迹单独核对。ROI 颜色计数可定位色块出现或消失，机械臂挡住色块时仅支持“被遮挡”。
- 盖住需要同时确认目标色块完全不可见、盖子对准已知位置并落稳、夹爪松开后盖子留在原位。夹爪或移动中的盖子完全挡住色块时，可先记“被遮挡”。盖下时只剩可辨边缘的帧，以及揭起时边缘刚恢复的帧，均记“部分可见”。
- 揭盖时依据画面更新部分可见或完整可见。盖子放妥与夹爪撤离各有时点。历史上的盖住或揭开经历可和之后相反的当前状态一起保留。

### `put_back_block`

- 首帧锁定原垫，分别复核起始、中央、回原垫。区分悬持于目标上方、已到位仍夹持、松夹后在支撑面保持。
- 按键过程中用当时可见的接近或下压描述进度。看清夹爪压到按键并抬离后，把过程改写为结果 “The button has been pressed.”。退臂仍在进行时可另写进度，退臂结束后保留按键结果及后续状态。机械按压和按钮触发的额外反馈各自取证。
- 遮挡后回看腕部，并以终帧确认动作完成后的可见位置。原垫身份与方块当前位置分别保留。

### `battery_try`

- 区分左右电池、相对上一次的调转、入槽与松夹。只有电极实物标记可读时才写绝对极性。
- 仪表观测要求表盘与枢轴可辨，指针可从枢轴辨认。留意镜头内臂上红标或高饱和反光。表盘被遮挡时记录最后可辨方向和当前遮挡。
- 从可读画面记录指针变化，从入槽和松夹证据判定试插结果。槽内、槽旁、暂时遮挡分别记录。两次试插可以产生相反结果，历史条目用对应尝试作为归属。把“某次尝试后看到指针转动”写作观察顺序，与物理因果分别处理。

## 其他官方任务的查证起点

以下检查项用于定位证据，具体判据随轨迹和视角复核。

| 任务 | 优先核对 |
| --- | --- |
| `observe_and_pickup` | 遮挡墙出现前的目标身份与位置，墙出现后的可见范围，以及抓取后目标与桌面的分离 |
| `press_button`、`blocks_ranking_try` | 按键身份、实际下压和释放、显示反馈与已尝试的顺序。每次重复按压按实际证据计数 |
| `classify_blocks`、`storage_blocks` | 每个物体的身份与分类依据，物体实际进入容器，松夹后留在容器里；一并夹持两块时分别核对 |
| `place_block_mat`、`rearrange_blocks` | 物体原位、目标垫、暂放位置与夹爪释放。一个官方子任务包含搬出又搬回时分别记录两次结果 |
| `swap_blocks`、`swap_T` | 两个物体的身份及各自原位，临时放置、交叉移动与最终互换。手移动到约定位置与物体落稳分别记录 |

## 怎样判断修订是否生效

对状态变化用四帧三视角看变化前、首次证据与结束后的画面。沿同一机位比较变化，并用同一帧其他视角查证遮挡和接触。官方切换前后查看实际监督点，核对当前目标 Memory、上一决策点参考 Memory 和可能落在采样间隙的短状态。回归用例覆盖过早写结果、延续旧动作、对象错绑、遮挡误判和失败中断。真实终帧仍夹持时，只记录画面支持的结果。按实际复核范围交付。

原始任务和命名见 [RMBench 官方仓库](https://github.com/RoboTwin-Platform/RMBench)。高层语言摘要思想见 [MEM](https://arxiv.org/abs/2603.03596v2)。
